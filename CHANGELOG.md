# Changelog

Todas las modificaciones notables del proyecto GameStore serán documentadas en este archivo.

El formato está basado en [Keep a Changelog](https://keepachangelog.com/es-ES/1.0.0/),
y este proyecto adhiere a [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [No Publicado]

### Añadido
- Documentación completa del proyecto
- Archivo de reglas para Amazon Q

## [0.3.0] - 2024-06-XX

### Añadido
- Implementación de GSAP ScrollSmoother para scroll suave
- Página de catálogo con filtrado y búsqueda
- Página de ofertas con countdown timer
- Página de quiénes somos
- Página de blog
- Página de carrito
- Página de cuenta de usuario

### Corregido
- Error de hidratación en HeroSection con partículas aleatorias
- Error de `class` vs `className` en componentes React
- Problemas con el countdown timer en OfertaCard
- Errores en la pasada de props a GameCard

## [0.2.0] - 2024-05-XX

### Añadido
- Navbar con menú responsive
- Animaciones con Framer Motion
- Componente HeroSection con carrusel
- Componente GameCard para mostrar juegos
- Componente OfertaCard para mostrar ofertas
- Fondo animado con partículas
- Esquema de colores cyberpunk/neón

### Cambiado
- Migración a Next.js 14 con App Router
- Implementación de Tailwind CSS con variables personalizadas

## [0.1.0] - 2024-04-XX

### Añadido
- Configuración inicial del proyecto con Next.js
- Estructura básica de directorios
- Configuración de Tailwind CSS
- Fuentes personalizadas (Orbitron, Exo 2)
- Página principal básica
